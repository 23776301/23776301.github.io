📝 私人笔记

笔记放在 GitHub 私有仓里，本页只是一个公开的「查看器」：用你的凭证通过 GitHub API 读取，再用自定义样式渲染。 页面本身不含任何笔记内容，别人打开也读不到——权限由 GitHub 仓库决定。

连接私有仓

在本机保存后，下次打开自动连接（仅存于你自己的浏览器 localStorage）。建议用 fine-grained token，只授权目标私有仓的 Contents: Read。
为什么这里用 PAT 而不是标准 OAuth？
GitHub 的 login/oauth/access_token 换 token 接口不返回 CORS 头，纯静态页面无法直接完成 OAuth 的 code→token 交换（实测无 Access-Control-Allow-Origin）。 要做「点按钮用 GitHub 登录」，需要一个极小的代理（如 Cloudflare Worker）替你把 code 换成 token。配置代理后可启用下面的 OAuth 模式；PAT 则无需任何服务端。
